# Fugs YEP/Galv Sprite Offset Fix

A compatibility patch for RPG Maker MV 1.6.3 that fixes the `SpriteOffsetX` conflict between Yanfly's Event Sprite Offset plugin and Galv's Camera Control.

| | |
|---|---|
| **Version** | 1.0.0 |
| **Engine** | RPG Maker MV 1.6.3 |
| **Plugin file** | `FugsYEP-GALV-SpriteOffsetFix.js` |
| **Requires** | Yanfly Event Sprite Offset and Galv Camera Control |
| **License** | MIT ([LICENSE](LICENSE)) |

## Install

1. Install and enable Yanfly's Event Sprite Offset and Galv's Camera Control.
2. Copy `FugsYEP-GALV-SpriteOffsetFix.js` into your game's `js/plugins/` folder.
3. Enable the patch after both prerequisite plugins in Plugin Manager.
4. Test a map with camera movement and event sprite offsets.

The patch has no parameters or plugin commands.
